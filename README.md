# Propwash 26.3 Family FPV

A Minecraft 26.3 (Fabric) modpack built around **Propwash FPV** drones.

## Install (Prism Launcher)

1. **Add Instance → Import**, paste this link, click **OK**:
   `https://raw.githubusercontent.com/ted-iak/propwash-pack/main/dist/Propwash.zip`
2. Click **Launch**. The first launch downloads the mods (a minute or two).
   If a window asks you to download a mod by hand, click its link and follow the steps.
3. In game, press **K** and set up your drone controller (about 30 seconds).

Updates install themselves every time you launch.
